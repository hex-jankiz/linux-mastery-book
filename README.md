### 🌟 مميزات النسخة الرقمية التفاعلية:
- **تقليب حقيقي ثلاثي الأبعاد (3D Flipbook):** يفتح الكتاب من اليسار إلى اليمين كما في الكتب العربية الحقيقية.
- **دعم كامل للهواتف والأجهزة اللوحية:** تقليب وتصفح ناعم باللمس والسحب بالإصبع.
- **دعم كامل للحواسيب:** تحكم بالماوس والأسهم ولوحة المفاتيح مع وضع ملء الشاشة.
- **مؤثرات صوتية واقعية:** صوت ورق ناعم وتفاعلي عند التقليب.
- **فهرس ذكي وسريع:** فهرس كامل لـ 37 فصلاً مع خاصية البحث الفوري والقفز المباشر لأي صفحة.
- **أوضاع قراءة متعددة:** وضع الورق الكلاسيكي (Sepia)، الوضع الليلي الداكن (Dark)، والوضع النهاري (Light)، مع إمكانية تكبير وتصغير حجم الخط.
